# ECNU GPA Plugin

在华东师范大学成绩页面显示学期、学年和累计的均绩、专绩及学分加权均分。所有计算在本地页面进行。

## 安装

### Chrome / Edge 扩展

下载并解压本仓库，打开 `chrome://extensions/` 或 `edge://extensions/`，开启开发人员模式，选择“加载已解压的扩展程序”，加载包含 `manifest.json` 的目录。打开成绩页面并刷新即可。

更新文件后，重新加载扩展并刷新成绩页面。浏览器扩展入口为 `content.js`。

### 油猴脚本

在 Tampermonkey 中新建脚本，将 `content-gf.js` 的完整内容粘贴并保存，然后刷新成绩页面。油猴脚本与浏览器扩展提供相同统计功能，选择其中一种安装即可，避免重复运行。

## 展示

- 最顶部显示累计统计，然后按学年汇总。
- 每个学期成绩表上方显示本学期统计。
- 每条统计栏为小字体单行布局：左侧为均绩、课程均分、门数和学分；右侧为专绩、专业均分、门数和学分。
- 固定列宽、数字右对齐；窄窗口可横向滚动统计栏。

## 计算口径

- 均绩：有效数字绩点按课程学分加权。
- 专绩：课程类别包含“专业”或“学科基础课”的课程，按有效数字绩点和学分加权。
- 课程均分和专业均分：分别以有效百分制成绩按学分加权，分母仅包含参与均分计算的课程学分。
- 绩点和百分制成绩分别判断有效性，空白、`--` 等不参与对应计算，不从等级反推百分制成绩。零绩点、零分正常计入。
- 汇总使用课程原始加权总和，最后显示时保留两位小数，不平均已舍入的学期结果。
- 行内门数和学分采用绩点口径；悬停可查看均分采用的门数和学分。
- 支持独立课程类别列，以及课程名称下方的“课程号 | 类别”。
- 支持“2025秋”“2026春”等学期标题，以及完整学年标题。秋季与次年春季、夏季归入同一学年。

统计仅覆盖当前页面已加载的课程，请显示全部学期后查看累计结果。重修课程按页面记录计入，不额外去重。类别或学年无法识别时会提示；此插件不替代学校官方成绩与审核口径。

## 验证

```sh
node --check content.js
node --check content-gf.js
```

两个入口的功能主体应保持一致。功能已在无头 Chromium 的模拟成绩页面验证，包括加权计算、空成绩、零分、课程分类、学年汇总、动态更新及列对齐；不同真实页面布局仍可能需要适配。
